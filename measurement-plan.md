# Measurement Plan

## Primary measures

- End-to-end onboarding cycle time
- Median queue time by function
- First-time-right intake rate
- Rework loops per case
- Unowned case count
- SLA breach rate
- Exception rate by category

## Evaluation approach

Collect at least several weeks of baseline data before the pilot. Compare like-for-like client segments, and distinguish structural improvement from volume or staffing changes. The repository does not claim a realised cycle-time reduction; the To-Be design creates a testable improvement hypothesis.
