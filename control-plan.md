# Control Plan

| Control | Owner | Frequency | Evidence |
|---|---|---|---|
| Mandatory-field validation | Process system | Every case | validation result |
| Compliance queue age review | Compliance lead | Daily | queue dashboard |
| Exception ownership check | Operations coordinator | Daily | exception register |
| Cases > SLA threshold | Process owner | Daily | escalation report |
| Rework-rate review | Process owner | Monthly | KPI trend |
| Process rule change | Governance owner | As needed | versioned decision record |

## Escalation threshold example

- Amber: case has waited > 2 business days in one queue.
- Red: case has waited > 5 business days, has no owner, or blocks contractual activation.
