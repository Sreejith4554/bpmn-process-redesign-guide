# Implementation Roadmap

## Phase 1 — Baseline
- Measure current cycle time by stage.
- Sample rework causes and handoff failure modes.
- Confirm regulatory and control requirements.

## Phase 2 — Design
- Agree common intake fields and entry criteria.
- Confirm target ownership model.
- Build To-Be BPMN and exception taxonomy.

## Phase 3 — Pilot
- Run with one client segment or region.
- Track cycle time, first-time-right rate and exception aging.
- Capture operational feedback weekly.

## Phase 4 — Scale
- Standardize SOPs and training.
- Automate low-risk routing and notifications.
- Create management dashboard and governance cadence.

## Phase 5 — Stabilize
- Review benefits against baseline.
- Tune thresholds and exception categories.
- Move improvements into continuous-improvement backlog.
