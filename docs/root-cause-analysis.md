# Root-Cause Analysis

## 5 Whys — Why is onboarding slow?

1. **Why are cases waiting?** Teams frequently wait for missing data or evidence.
2. **Why is information missing?** Intake requirements differ by function and are checked late.
3. **Why are requirements checked late?** There is no shared entry criterion before compliance review.
4. **Why is there no shared criterion?** Each function owns its own tracker and handoff practice.
5. **Why are trackers fragmented?** The process evolved function-by-function rather than end-to-end.

## Cause categories

| Category | Observed design issue | To-Be response |
|---|---|---|
| Process | Duplicate intake and re-entry | Capture once; validate before routing |
| People | Unclear case owner | Named relationship/case owner |
| Technology | Separate trackers | Single case ID and shared status model |
| Governance | No SLA / exception taxonomy | Explicit thresholds and queue types |
| Measurement | No cycle-time breakdown | Timestamp each stage and queue |
